# Nyaya Sahayaka - Multilingual AI Legal & Government Scheme Assistance

A comprehensive web platform that provides AI Legal Assistance and Indian Government Welfare scheme discovery using RAG and Real-World Datasets.

## System Architecture

- **Frontend**: Next.js (App Router), React, Tailwind CSS, Shadcn UI, Framer Motion
- **Authentication**: Clerk
- **Backend/DB**: Convex
- **AI Microservice**: Python FastAPI, LangChain, FAISS, SentenceTransformers (IndicBERT)

---

## 🚀 Setup Instructions

### 1. Frontend Setup (Next.js + Convex + Clerk)

1. **Configure Environment Variables**:
   In `legal-agent-web`, create a `.env.local` file with your Clerk and Convex keys:
   ```env
   NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_clerk_key
   CLERK_SECRET_KEY=your_clerk_secret

   # Generated by Convex
   CONVEX_DEPLOYMENT=your_convex_deployment
   NEXT_PUBLIC_CONVEX_URL=your_convex_url
   ```

2. **Initialize Database Schema on Convex**:
   ```bash
   cd legal-agent-web
   npx convex dev
   ```
   *(This will prompt you to create a Convex project and push the schema in `convex/schema.ts`)*

3. **Start the Development Server**:
   ```bash
   npm run dev
   ```

### 2. AI Back-end Setup (FastAPI Microservice)

1. **Install Python Dependencies**:
   ```bash
   cd legal-agent-ai
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

2. **Download Real Datasets**:
   Because we use REAL datasets rather than mock data:
   - Go to Kaggle (e.g. `kaggle datasets download -d asaniczka/indian-penal-code-crpc-datasets`) or `data.gov.in`.
   - Download the CSV files for IPC Sections, CrPC Sections, or Government Welfare Schemes.
   - Place these `.csv` files inside `/legal-agent-ai/data/`.
   - *Requirement: CSV must have an `content` column representing the text to embed.*

3. **Ingest Data into Vector DB (FAISS)**:
   ```bash
   python scripts/ingest.py
   ```
   *(This will process your real Indian Legal datasets and build the embedded FAISS index for the microservice.)*

4. **Start the Microservice API**:
   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```

---

*Note: The Chat UI in `/legal-agent-web/src/app/chat/page.tsx` is currently stubbed to simulate the round-trip from the frontend to Convex. To connect the frontend directly to the python backend, you will need to add a Convex HTTP action (`convex/ai.ts`) that POSTs to `http://localhost:8000/api/chat`.*
